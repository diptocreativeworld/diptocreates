# Dipto Creates

Cinematic portfolio for Farhan Masud Dipto. Static HTML, CSS and JavaScript; serve `dist/` as the document root. No build dependencies.

This source matches the restored material-worlds version, including desktop and native portrait films and the buffered scroll loader. The later traveller expansion was undone and is not included.

Current preview: https://dipto-creates-material-worlds.fmasud4479.chatgpt.site/

Custom domain diptocreates.com is attached in Sites but DNS and TLS validation remain pending. Hosting is managed through Sites; pushing to this repository does not automatically deploy it. AI-assisted imagery and motion are included as personal concept studies.
